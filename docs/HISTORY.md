# 早期本地测试版

以下按现有开发文档整理，不补造发布日期、Git 标签或旧版下载地址。旧安装包仅有部分本地留存，本公开仓库不分发这些版本。

| 本地阶段 | 已记录的主题 |
| --- | --- |
| Android 第六至九版 | 原生任务提醒、精确提醒、通知样式、后台诊断；后续确认 iQOO 后台耗电策略会影响送达 |
| Android 第十、十一版 | 自动记账初版、支付来源识别开关、系统权限跳转与刷新 |
| Android 第十二至十六版 | 回收区清空、返回行为、手机紧凑布局、编辑正文键盘适配 |
| Android 第十七至十九版 | 白条详情补记、支付宝样本适配、识别状态与账单审核探索 |

“已有实现”和“所有设备稳定可用”不是一回事。自动记账在实际体验中存在漏识别、响应与交互不足，已转向独立应用，不再作为个人工作台功能继续发布。

当前可下载版本：[v0.1.1](RELEASE_v0.1.1.md)。
