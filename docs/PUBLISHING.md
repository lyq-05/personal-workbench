# 发布流程

公开仓库仅包含发布材料。源码在独立 Private 仓库，禁止把源码或现有开发 Git 历史推送到这里。

1. 在开发目录修改并验证，生成 Windows 安装程序和 Android APK。
2. 确认版本、签名、数据兼容与真实验收边界。更新 README、CHANGELOG、本版 RELEASE 文档。
3. 安装包使用 ASCII 文件名，计算 SHA-256；大文件作为 Release 附件上传，不提交 Git。
4. 截图用隔离或虚构数据，检查无私人内容；保留 docs/screenshots 中的精选图片。
5. 检查 `git ls-files` 仅有允许的文档、图片和校验文件，再提交版本标签与分支。
6. 建立草稿 Release，使用同版文档作正文，上传安装包和 SHA256SUMS，校验大小与哈希后发布。
7. 检查下载直链、Release 正文、截图及 GitHub Camo 徽章实际返回内容。
8. 私有源码备份单独校验仓库 Private 属性、文件清单、远程分支 SHA 和版本标签。密钥、本机配置、用户数据及缓存不进仓库，签名密钥另行安全备份。

v0.1.1 是体验版，不能为了版本徽章显示而改为正式版。源码备份是当前快照，不是自动同步。
